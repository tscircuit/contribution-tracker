# Changelog 2026-09

Key 2026-09 highlights
- Autorouting & routing tools
  – New “simplify” autorouter preset (props #723, core #3581) and Pipeline 11 trace-simplification (autorouter #2335)
  – Autorouter now exposes cache decisions & progress (core #3655, autorouter #2370) and reuses static connectivity during Pipeline 9 repair (#2349)
  – Fanout-solver gains incremental steps plus major AM62L DDR breakout fixes & perf boosts (#131, #141, #149, #155)
  – Length-matching solver prevents reversed diff-pair spines (#61)
  – Schematic-trace-solver: large set of crossing-avoidance, rail-merge and dog-leg-removal fixes (#1013, #1045, #1054, #1064)

- PCB / fabrication correctness
  – Copper-pour solver clears around oval plated holes (copper-pour-solver #86; integrated in core #3593, #3666)
  – Gerber exporter deduplicates via drills & favours physical-layer data (#159, #158, #154)
  – Checks: plated-pill pad-clearance geometry fixed (#257) and 2-pin switch self-short warning added (#263)

- Format import / export
  – AltiumTS: Bus & BusEntry support, binary polygon cut-outs, overbar text & sheet-size fixes (#119, #115, #113)
  – circuit-json-to-Altium/KiCad: preserves filenames, graphics, cut-outs, and fixes fractional coords (#93-106, #491-502)
  – KiCadTS now supports KiCad 10 property flags (#67) and board-text sizing fixes in reverse import (#180)
  – EasyEDA-converter: accurate CAD footprint sizing & multiple schematic rendering fixes (#540-543)

- Core platform
  – Core upgraded schematic-trace-solver to v0.0.178 (#3582) and added fabrication notes for internally-tied pads (#3650)
  – Duplicate traces removed from local autorouter stage (#3583) and footprint-cutout ownership associated to components (#3628)
  – Net-label superscripts disambiguate same-name islands (core #3660) with SVG rendering support (circuit-to-svg #712)

- UI / CLI / Web
  – tscircuit.com can export all schematic sheets in image downloads (#4729) and sync selected file with URL (#4748)
  – SVG server can now render PCB debug objects on demand (svg.tscircuit.com #2186)
  – CLI surfaces autorouter execution metadata and shortens cache keys (#4604-4605); concurrent installs serialized (#4590)

- Libraries & content
  – TI repo adds MSPM0/M33 MCUs, Automotive Window Module example & improved subcircuit picker (#224-235)
  – Quick-configure supplies multiple AM62L DDR breakout templates (#11-15)
  – Biscuit-Boards V2 plus new board examples (#106-111)

- Documentation
  – New DDR routing guide & end-to-end phase visuals (docs #862, #864)
  – Clarified automatic copper-pours and routing guidance (#865)

- Miscellaneous
  – Circuit-json adds styled pin-label runs & inline superscripts (#748-755)
  – Copper-pour/autorouter capacity bumped to v0.0.874 (#3653)
