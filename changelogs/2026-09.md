# Changelog 2026-09

- Autorouting
  - Added "simplify autorouter" preset + dedicated routing phase for cleaner results ([props#723](https://github.com/tscircuit/props/pull/723), [core#3581](https://github.com/tscircuit/core/pull/3581))
  - Pipeline 11 now auto-simplifies traces ([tscircuit-autorouter#2335](https://github.com/tscircuit/tscircuit-autorouter/pull/2335))
  - Removed duplicated traces in local autorouter stage ([core#3583](https://github.com/tscircuit/core/pull/3583))

- Schematic & Trace Quality
  - Numerous label/trace fixes: no parallel-host overlaps, doglegs, or duplicate grounds; ground labels stay aligned; merges same-net rails; avoids anchoring crossings ([sts#1038](https://github.com/tscircuit/schematic-trace-solver/pull/1038), [sts#1054](https://github.com/tscircuit/schematic-trace-solver/pull/1054), [sts#1008](https://github.com/tscircuit/schematic-trace-solver/pull/1008), [sts#1017](https://github.com/tscircuit/schematic-trace-solver/pull/1017), [sts#1020](https://github.com/tscircuit/schematic-trace-solver/pull/1020), [sts#1013](https://github.com/tscircuit/schematic-trace-solver/pull/1013), [sts#1052](https://github.com/tscircuit/schematic-trace-solver/pull/1052), [sts#1045](https://github.com/tscircuit/schematic-trace-solver/pull/1045))

- PCB / Manufacturing
  - Fixed plated-pill pad clearance geometry ([checks#257](https://github.com/tscircuit/checks/pull/257))
  - Copper pours now clear oval plated holes correctly ([copper-pour-solver#86](https://github.com/tscircuit/copper-pour-solver/pull/86))
  - Prevented zero-length via copper and deduplicated drill hits in Gerber exports ([cj2g#154](https://github.com/tscircuit/circuit-json-to-gerber/pull/154), [cj2g#159](https://github.com/tscircuit/circuit-json-to-gerber/pull/159), [cj2g#158](https://github.com/tscircuit/circuit-json-to-gerber/pull/158))
  - Added fabrication notes for internally connected pads ([core#3650](https://github.com/tscircuit/core/pull/3650))
  - Footprint cutouts now stay linked to their components ([core#3628](https://github.com/tscircuit/core/pull/3628), [checks#259](https://github.com/tscircuit/checks/pull/259))

- Format / CAD Support
  - KiCad: support v10 property flags + fix schematic geometry & component links ([kicadts#67](https://github.com/tscircuit/kicadts/pull/67), [k2cj#177](https://github.com/tscircuit/kicad-to-circuit-json/pull/177), [k2cj#176](https://github.com/tscircuit/kicad-to-circuit-json/pull/176))
  - Altium export preserves filenames, silkscreen graphics, board cutouts/slots, polygon cutouts and component parameters ([cj2a#102](https://github.com/tscircuit/circuit-json-to-altium/pull/102), [cj2a#103](https://github.com/tscircuit/circuit-json-to-altium/pull/103), [cj2a#104](https://github.com/tscircuit/circuit-json-to-altium/pull/104), [cj2a#105](https://github.com/tscircuit/circuit-json-to-altium/pull/105), [cj2a#101](https://github.com/tscircuit/circuit-json-to-altium/pull/101))
  - EasyEDA importer now derives footprint size from model bounds ([eec#540](https://github.com/tscircuit/easyeda-converter/pull/540))
  - Circuit-JSON gains component ownership metadata for PCB cutouts ([circuit-json#745](https://github.com/tscircuit/circuit-json/pull/745))

- Fan-out & Length Matching
  - Incremental fan-out solving and multiple AM62L routing fixes, including browser support ([fos#131](https://github.com/tscircuit/fanout-solver/pull/131), [fos#134](https://github.com/tscircuit/fanout-solver/pull/134), [fos#138](https://github.com/tscircuit/fanout-solver/pull/138), [fos#141](https://github.com/tscircuit/fanout-solver/pull/141), [fos#150](https://github.com/tscircuit/fanout-solver/pull/150))

  - Editor keeps selected file synced with URL and avoids opening lockfiles ([tscircuit.com#4748](https://github.com/tscircuit/tscircuit.com/pull/4748), [tscircuit.com#4734](https://github.com/tscircuit/tscircuit.com/pull/4734))
