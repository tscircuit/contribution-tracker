# Changelog 2026-09

Key changes shipped in 2026-09

- Autorouter
  – Added end-to-end trace-simplification: new preset (props #723) + Core support (core #3581) + Pipeline 11 improvements & shortcut heuristics (autorouter #2335, #2393)
  – Better Pipeline 9 repair: reuse static connectivity, ignore connected pads, accept same-net copper, cache DRC candidates, progress reporting (autorouter #2349, #2390, #2361, #2381, #2370)
  – New dataset/benchmark tooling (autorouter #2333, #2407) and version bumps to v0.0.882

- Fan-out & DDR
  – Incremental fanout solving and dense AM62L fixes with multi-sample benchmarks (fanout-solver #131, #134, #141, #149, #154)
  – Quick-configure pages for left / top / bottom / right DDR breakouts (quick-configure #11-15)
  – Docs: end-to-end DDR routing guide & boundaries (docs #862, #864)

- Schematic trace solver
  – Align exits/rails, merge same-net rails, avoid duplicate stubs & doglegs, prevent label-trace crossings (schematic-trace-solver #1020, #1045, #1054, #1052, #1061)
  – Ground-net handling & bug-report reproductions (#1008, #1048, #1063)

- Copper & Gerber
  – Clear pours around oval plated holes (copper-pour-solver #86) + implicit pour updates (core #3666)
  – Gerber export: deduplicate via drills, zero-length vias, physical-layer preference (circuit-json-to-gerber #154, #158-159)

- Checks / DRC
  – Fix plated-pill pad clearance (checks #257)
  – Report self-shorted pushbuttons & allow components over owned cutouts (checks #262-263, #259)

- Data & format libraries
  – Net-label superscripts and styled pin-label runs across JSON & SVG (circuit-json #749-755, circuit-to-svg #712)
  – Component-owned PCB cutouts (circuit-json #745, core #3628)

- Converters / CAD I/O
  – KiCad 10 flag support & schematic fixes (kicadts #67, kicad-to-circuit-json #176-179)
  – Altium export preserves polygons, bus objects, notes, cut-outs (altiumts #115, #119; circuit-json-to-altium #102-106, #115)
  – EasyEDA: real L0805 inductor docs, CAD size & body-fill fixes (easyeda-converter #535, #540-543)
  – KiCad export: OBJ-only 3D models, bottom-mount displays, fab-note paths (circuit-json-to-kicad #494-502, #510)

- TI ecosystem
  – Subcircuit picker with block filtering & MCP recommendations; added MSPM33C321x / MSPM0 MCUs and Automotive Window Module example (ti #221-235)

- CLI & Infra
  – CLI surfaces autorouter metadata, shortens cache keys, prevents concurrent installs (cli #4590, #4604-4605)
  – Export all schematic sheets in downloads (tscircuit.com #4729) and multiple runframe/eval version bumps for stability

- Miscellaneous
  – Copper-pour-aware fabrication notes (core #3650)
  – Circuit-JSON schematic warning for confusing net names (core #3657)
  – PCB debug object rendering on demand (svg.tscircuit.com #2186)

Version bumps, test reproductions, and dependency refreshes are omitted for brevity.
