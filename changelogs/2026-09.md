# Changelog 2026-09

- Added "simplify autorouter" preset and routing phase for cleaner, shorter traces ([props#723](https://github.com/tscircuit/props/pull/723), [core#3581](https://github.com/tscircuit/core/pull/3581))
- Autorouter Pipeline 11 trace‐simplification pass reduces segment count ([tscircuit-autorouter#2335](https://github.com/tscircuit/tscircuit-autorouter/pull/2335))
- SVG viewer can now render PCB debug objects on demand ([svg.tscircuit.com#2186](https://github.com/tscircuit/svg.tscircuit.com/pull/2186))
- Image downloads from tscircuit.com now export every schematic sheet, not just the first ([tscircuit.com#4729](https://github.com/tscircuit/tscircuit.com/pull/4729))
- Fixed plated-pill pad-to-copper clearance calculation ([checks#257](https://github.com/tscircuit/checks/pull/257))
- Copper pours correctly clear around oval plated holes ([copper-pour-solver#86](https://github.com/tscircuit/copper-pour-solver/pull/86))
- Schematic trace solver refinements: cleaner ground-label placement, aligned exits, rerouted crossings, and eliminated duplicate labels ([schematic-trace-solver#1017](https://github.com/tscircuit/schematic-trace-solver/pull/1017), [#1008](https://github.com/tscircuit/schematic-trace-solver/pull/1008), [#1020](https://github.com/tscircuit/schematic-trace-solver/pull/1020), [#1013](https://github.com/tscircuit/schematic-trace-solver/pull/1013), [#1038](https://github.com/tscircuit/schematic-trace-solver/pull/1038))
- KiCad importer: added support for KiCad 10 property flags and fixed source geometry/links ([kicadts#67](https://github.com/tscircuit/kicadts/pull/67), [kicad-to-circuit-json#177](https://github.com/tscircuit/kicad-to-circuit-json/pull/177), [#176](https://github.com/tscircuit/kicad-to-circuit-json/pull/176))
- TI library: new MSPM33C321x/MSPM0 MCUs, system blocks, and category-filtered subcircuit picker; plus symbol fixes ([ti#224](https://github.com/tscircuit/ti/pull/224), [#225](https://github.com/tscircuit/ti/pull/225), [#227](https://github.com/tscircuit/ti/pull/227), [#226](https://github.com/tscircuit/ti/pull/226))
- Length-matching solver blocks invalid differential-pair spine reversals to prevent crashes ([length-matching-solver#61](https://github.com/tscircuit/length-matching-solver/pull/61))
- Fanout solver now runs incrementally for faster, more controllable iterations ([fanout-solver#131](https://github.com/tscircuit/fanout-solver/pull/131))
- Matchpack maintains crystal-circuit alignment when grounded loads are inserted ([matchpack#237](https://github.com/tscircuit/matchpack/pull/237))
- Biscuit-Boards LightBurn export gains uniform solder-paste layer option ([biscuit-boards#103](https://github.com/tscircuit/biscuit-boards/pull/103))
- Altium exporter now outputs precise fractional coordinates ([circuit-json-to-altium#93](https://github.com/tscircuit/circuit-json-to-altium/pull/93), [ti#223](https://github.com/tscircuit/ti/pull/223))
