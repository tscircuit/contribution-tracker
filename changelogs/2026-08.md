# Changelog 2026-08

Key highlights for 2026-08

- Differential-pair DRC
  – RFC #13 + core #3011/3017 now warn when differential pairs are not strictly point-to-point.

- Pipeline 9 autorouter preview
  – core #3023, #3057-#3086, props #784/788, cli #4052 introduce selectable “beta_pipeline9”, named phase events, square snapshots and preserved pre-routed traces.

- Autorouter DRC / repair
  – SMT-pad escapes, rotated-pad DRC and preloaded-trace feedback fixes (autorouter #1941, #1950, #1954, #1968-#1977).

- Placement/DRC controls
  – User-set PCB pack solver timeout & optional placement-DRC blocking (core #3015, props #785/786, cli #4071).

- 3D viewer overhaul
  – Physically-based materials, surface relief, mirrored lighting, grid & reference toggles, off-axis CAD sizing fix (3d-viewer #960-#968).

- Copper-pour trace clipping everywhere
  – pcb-viewer #932/#936, circuit-to-svg #654/#658, 3d-viewer #965 ensure traces stop at pour boundaries in 2D & 3D.

- Silkscreen rendering
  – circuit-to-canvas #258 now outputs PCB silkscreen graphics.

- Footprint improvements
  – Default circular BGA pads (footprinter #760), new SOT-143 & linear SMD packages (#774/#781), clearer asymmetric-QFN names (#770).

- Gerber / STEP fidelity
  – Keep rectangular-pad rotation (c-json-to-gerber #134), close board-outline & hole loops in STEP export (#123-#125).

- CLI UX upgrades
  – Source diagnostic checks (#4062), rats-nest preview (#4058), named-phase debug (#4052), correct `--ignore-placement-drc` behaviour (#4071).

- Schematic engine tweaks
  – Dashed section dividers (#3012); cross-subcircuit net labels (#2924/#3036); canonical net-label text & clearer diff-pair warnings (#3016-#3017); auto-decoupling detection/placement (#2962/#3032/#3062).

- Trace-solver refinements
  – Rail label alignment, spike avoidance, shorter detours, new bug-report fixtures (solver #771/#772/#781/#785).

- Library growth
  – Added AM62L32 SoC, CC2564C Bluetooth stack, MSP430 audio host, power/BMS ICs plus complete Bluetooth-speaker system example (ti #93-#109, system-block-designer #64/#65).

- CAD / EDA tooling
  – Native Altium schematics rendered as SVG (altiumts #37/#40); EasyEDA symbol scaling & stroke-width fixes (easyeda-converter #420/#422).

- Performance wins
  – Faster packing via caching & indexed look-ups (calculate-packing #120/#121); shared triangle scan in GLTF export (#176).
