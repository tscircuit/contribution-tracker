# Changelog 2026-08

- Enforce point-to-point routing for differential pairs; compiler now warns on violations ([rfc #13](https://github.com/tscircuit/rfc/pull/13), [core #3011](https://github.com/tscircuit/core/pull/3011), [core #3017](https://github.com/tscircuit/core/pull/3017))
- 3D viewer overhaul: physically-based materials, realistic surface relief, grid & reference objects, brighter underside lighting, and fixed off-axis CAD scaling ([3d-viewer #960](https://github.com/tscircuit/3d-viewer/pull/960), [#964](https://github.com/tscircuit/3d-viewer/pull/964), [#966](https://github.com/tscircuit/3d-viewer/pull/966), [#967](https://github.com/tscircuit/3d-viewer/pull/967), [#961](https://github.com/tscircuit/3d-viewer/pull/961))
- Traces are now correctly clipped/visible when copper pours are hidden across viewers and exporters ([pcb-viewer #932](https://github.com/tscircuit/pcb-viewer/pull/932), [#936](https://github.com/tscircuit/pcb-viewer/pull/936), [circuit-to-svg #654](https://github.com/tscircuit/circuit-to-svg/pull/654), [#660](https://github.com/tscircuit/circuit-to-svg/pull/660), [3d-viewer #965](https://github.com/tscircuit/3d-viewer/pull/965))
- circuit-to-canvas can now render PCB silkscreen graphics ([circuit-to-canvas #258](https://github.com/tscircuit/circuit-to-canvas/pull/258))
- CLI QoL: rats-nest preview, named autorouter phase debugging, source diagnostic checks, proper `--ignore-placement-drc`, and direct circuit.json support ([cli #4058](https://github.com/tscircuit/cli/pull/4058), [#4052](https://github.com/tscircuit/cli/pull/4052), [#4062](https://github.com/tscircuit/cli/pull/4062), [#4071](https://github.com/tscircuit/cli/pull/4071), [#4097](https://github.com/tscircuit/cli/pull/4097))
- Beta Pipeline9 autorouter integration with phased snapshots and per-pipeline cache ([core #3023](https://github.com/tscircuit/core/pull/3023), [#3057](https://github.com/tscircuit/core/pull/3057), [#3083](https://github.com/tscircuit/core/pull/3083))
- Schematics: dashed section dividers and inline net labels on point-to-point traces ([core #3012](https://github.com/tscircuit/core/pull/3012), [#3085](https://github.com/tscircuit/core/pull/3085))
- Footprinting & Gerber: default circular BGA pads, new SOT-143 & linear SMD footprints, recovered staggered headers, preserved SMT pad rotation ([footprinter #760](https://github.com/tscircuit/footprinter/pull/760), [#774](https://github.com/tscircuit/footprinter/pull/774), [circuit-json-to-footprinter #85](https://github.com/tscircuit/circuit-json-to-footprinter/pull/85), [circuit-json-to-gerber #134](https://github.com/tscircuit/circuit-json-to-gerber/pull/134))
- Chip footprints in JSCAD now named by pads, not package size ([jscad-electronics #319](https://github.com/tscircuit/jscad-electronics/pull/319))
- Circuit JSON metadata enriched with source_trace_id and provenance ([circuit-json #688](https://github.com/tscircuit/circuit-json/pull/688), [core #3120](https://github.com/tscircuit/core/pull/3120))
