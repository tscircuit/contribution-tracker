# Changelog 2026-08

Key user-visible changes shipped in August 2026

PCB / Routing
- Enforced point-to-point differential pairs – RFC #13 + core #3011/3017
- Capacity autorouter upgraded for phased “Pipeline9” routing (#3057, #3082) incl. named phase events (#3020) and snapshot preservation (#3021)
- Autorouter fixes: restore pre-loaded-trace DRC (#1950), inject explicit initial connectivity (#1954), keep original pad geometry in relaxed DRC (#1968), length-matching solver update (#1974)
- Decoupling awareness – automatic detection (#3032, #2962) and schematic layout improvements via Matchpack 0.0.70 (#3029, #3062)
- Breakout & parent-trace repair fixes (#3044) and four-pin crystal length propagation (#3014)
- New PCB pack-solver timeout + CLI flag to ignore placement DRC (props #785/786, cli #4071)

Visualization & Viewers
- 3D-viewer overhaul with PBR materials + realistic surface relief (#960) and lighting / grid / texture-clipping tweaks (#964-#968)
- SVG / viewer trace clipping at copper-pour boundaries (circuit-to-svg #654/#658, pcb-viewer #932) and courtyard bounds fix (#652)
- Canvas renderer now draws PCB silkscreen graphics (circuit-to-canvas #258)

Data & Formats
- circuit-json now records source_trace_id (#688) with matching diagnostics in circuit-json-util #113
- Gerber export preserves rotated rectangular SMT pads (#134); STEP export fixes open outline & hole loops (#123/#125)
- Footprinter: default circular BGA pads (#760), full QFN pad names (#770) and generic linear SMD pad footprint (#781)

Schematic Solver / Trace Solver
- Dashed section-divider lines (#3012); canonical net-label text bounds (#3016)
- Rail/label alignment, spike avoidance & shorter detours (#772/#774/#781/#785) plus RP2040 label-collision repro (#780)

Libraries & Content
- Dozens of new TI subcircuits incl. AM62L32 SoC, Bluetooth-audio stack & power parts (#93-#109) with complete speaker system example (system-block-designer #65)
- New MSP430 Bluetooth audio host, CC2564C controller and routed PCB layouts (#103/#106)

CLI & Tooling
- CLI now shows rats-nest in autorouter-start image (#4058) and supports named-phase debug output (#4052) & source-diagnostics checks (#4062)
- AltiumTS exports native schematic SVGs (#37) and adds scroll-wheel zoom (#40)

Performance / Infrastructure
- calculate-packing caching & pruning (#119/#120); matchpack grounded-load reuse (#212) and rail-gap consistency (#204)
- JLCSearch full-catalog + nightly stock sync with resilient retries (#438-#443)
- Structured post-processing errors from length-matching-solver #39

Miscellaneous
- Common #92 prevents duplicate subcircuit child names
- RFC / docs: how-to prompt AI for circuit creation (docs #835)
