# Changelog 2026-08

- Differential-pair integrity
  – RFC #13 adds mandatory point-to-point diff-pair rule  
  – core #3011/#3017 warn & clarify when rule is violated

- Autorouter leap forward
  – Core #3020/#3057/#3084 introduce “Pipeline 9” phased routing, explicit phase events and versioned pipelines  
  – Upgrades through v0.0.772, length-matching & via-repair fixes, preserved pre-routed traces (#3021)

- Copper-pour clipping everywhere
  – circuit-to-svg #654/#658, pcb-viewer #932, 3d-viewer #965 clip traces/textures at pour edges → faster, cleaner visuals

- 3D viewer overhaul
  – 3d-viewer #960 switches to PBR materials & realistic surface relief  
  – New grid / reference object toggles (#966-#968)

- Schematic & layout quality
  – Dashed section dividers (core #3012)  
  – Automatic decoupling detection & placement tweaks (core #2962, #3045; matchpack #202)  
  – Four-pin crystal length propagation fixed (core #3014)  
  – Cross-boundary net labels now solved (core #3036)  
  – Parent-trace breakout fix (core #3044)

- Capacity / pack solver tuning
  – Configurable PCB-pack timeout (props #785, core #3015)  
  – calculate-packing optimisations (#120/#121)

- Footprint upgrades
  – Circular BGA pads for KiCad parity (footprinter #760)  
  – New SOT-143 (#774) & generic linear SMD pads (#781)

- CLI / tooling enhancements
  – Named autorouter-phase debugging & source diagnostics (cli #4052/#4062)  
  – --ignore-placement-drc now truly unblocks routing (cli #4071)

- Ecosystem & content additions
  – Bluetooth-speaker system example and AM62L32 SoC blocks (ti #106/#107, system-block-designer #65)  
  – Native Altium schematic SVG export & zoom (altiumts #37/#40)  
  – Gerber keeps arbitrary SMT-pad rotation (circuit-json-to-gerber #134)  
  – circuit-json now carries source_trace_id for easier debugging (#688)
