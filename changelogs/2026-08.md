# Changelog 2026-08

- Differential-pair integrity: new rule demands true point-to-point routing, with clear warnings when violated ([rfc/#13](https://github.com/tscircuit/rfc/pull/13), [core/#3011](https://github.com/tscircuit/core/pull/3011), [core/#3017](https://github.com/tscircuit/core/pull/3017))
- 3D viewer overhaul: physically-based materials & real surface relief for far more realistic PCB renders ([3d-viewer/#960](https://github.com/tscircuit/3d-viewer/pull/960)); also stops off-axis CAD models from shrinking ([3d-viewer/#961](https://github.com/tscircuit/3d-viewer/pull/961))
- PCB canvas gains silkscreen graphic rendering ([circuit-to-canvas/#258](https://github.com/tscircuit/circuit-to-canvas/pull/258))
- Schematics: section divider lines now appear dashed ([core/#3012](https://github.com/tscircuit/core/pull/3012)); rail labels relocate to avoid crossing traces ([schematic-trace-solver/#781](https://github.com/tscircuit/schematic-trace-solver/pull/781))
- Autorouter respects decoupling-capacitor constraints during source render ([core/#2962](https://github.com/tscircuit/core/pull/2962))
- New CLI diagnostics: adds source-level checks and rats-nest preview at autorouter start ([cli/#4062](https://github.com/tscircuit/cli/pull/4062), [cli/#4058](https://github.com/tscircuit/cli/pull/4058))
- Footprints: default BGA pads switched to circular for KiCad parity ([footprinter/#760](https://github.com/tscircuit/footprinter/pull/760)); SOT-143 package added ([footprinter/#774](https://github.com/tscircuit/footprinter/pull/774))
- Gerber export now preserves arbitrary rectangular SMT-pad rotations ([circuit-json-to-gerber/#134](https://github.com/tscircuit/circuit-json-to-gerber/pull/134))
- PCB viewer shows traces even when copper pours are hidden ([pcb-viewer/#936](https://github.com/tscircuit/pcb-viewer/pull/936))
- Altium projects: native schematic images rendered as SVG ([altiumts/#37](https://github.com/tscircuit/altiumts/pull/37))
- System-level design: complete Bluetooth-speaker example added ([system-block-designer/#65](https://github.com/tscircuit/system-block-designer/pull/65))
