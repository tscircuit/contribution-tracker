# Changelog 2026-10

Key 2026-10 highlights

- Cross-view navigation
  – Schematic Viewer #283 + Runframe #5568 + PCB Viewer #1068: “Show on PCB” jumps from a schematic part to the matching PCB footprint and auto-focuses it.

- Part availability & pricing
  – Schematic Viewer #282: live JLC stock / price in part sidebar.
  – Parts-engine #61, Props #915, Core #4424/#4429: supplier-based availability warnings, CLI #5180 enables them by default.

- Fabrication graphics upgrades
  – Filled fabrication note paths preserved across converters (#595 EasyEDA, #300 Canvas, #812 SVG) and viewers (#5569 Runframe).
  – Dark tented-via centers in SVG/Canvas/PCB Viewer (Core #4432, SVG #814, Canvas #304, PCB Viewer #1074).
  – Uniform fabrication path opacity (SVG #813, Canvas #302).

- Return-current simulation plumbing
  – Circuit-json #887 schema + SVG #818: render selected PCB return-current results.

- Schematic QA & placement analysis
  – Placement-analysis #211/#218/#215: detect resistors across pins, mis-routed RC branches, backward LED chains.
  – Core #4440 + Circuit-json #881 + SVG #815: warn when sheets use non-default sizes / styling.

- Assembly & mechanical modeling
  – Core #4444 + Props #919: first-class generic assembly.part support.
  – Modelprinter & JSCAD-electronics: dozens of new mechanical contracts/renderers (T-slot extrusions/corners/gussets, shaft collars & couplers, springs, bearings, nuts/bolts, hollow positioning arm tube, etc.).
  – Cableprinter #10 & Core #4416/#4420/#4417: configurable adapter cables, bullet connectors, auto-aligned JST motor cables.

- PCB fabrication accuracy
  – Core #4434: generate solder paste for pill pads.
  – Core #4446: preserve bus target lengths; Checks #396 fixes false copper-pour shorts.

- 3D & web viewers
  – 3D Viewer #1017: render cad_cable elements; website adds camera presets & GLB downloads (svg.tscircuit.com #2484/#2476).

- Miscellaneous developer tooling
  – CLI #5201 removes legacy alias; multiple bumps sync latest schematic-placement analysis 0.0.46.
