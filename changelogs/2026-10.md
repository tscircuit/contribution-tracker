# Changelog 2026-10

- Cross-view navigation
  – “Show on PCB” added to schematic context menu and wired through runframe & PCB viewer (#283, #5568, #1068)

- Component sourcing insights
  – JLC price/stock shown in schematic part details (#282)
  – Parts-engine gains JLC availability + price lookup (#61) and CLI enables checks by default (#5180)
  – Core issues opt-in availability warnings for explicitly listed suppliers (#4424, #4429)

- Higher-fidelity fabrication graphics
  – Filled fabrication note paths now preserved across SVG, Canvas, EasyEDA & PCB viewer (#812, #300, #595, #302, #1074)
  – Dark centers rendered on tented vias in all viewers (#4432, #814, #304)

- Smarter schematic placement analysis
  – Detect resistors straddling chip pins, backward LED chains and mis-aligned RC branches (#211, #215, #218)

- Generic mechanical & assembly support
  – New assembly.part props + core support (#919, #4444)
  – Dozens of new model contracts & renderers: T-slot hardware, shaft collars/couplers, bearings, springs, grommets, hollow tubes, etc. (modelprinter #20-38, jscad-electronics #410-428, #445)

- Cable & connector improvements
  – Automatic JST PH/SH motor cable headers and pin-1-aware plug orientation (#4417, #426, #424)
  – Compose generic adapter cables with independently specified ends (#10)

- PCB accuracy & DRC
  – Generate solder paste for pill pads (#4434)
  – Preserve bus target length for routing/DRC (#4446)
  – Bus-lanes-solver handles blocked escapes & full-board AM3352 sample (#42, #43)

- Simulation & analysis outputs
  – SVG can now render PCB return-current simulation layers (#818)

- Footprint customization
  – Custom pin-row courtyard dimensions allowed in Footprinter (#908)

- CAD export enhancements
  – Parasolid export merges coplanar faces and uses native entities (#jscad-to-parasolid #2, parasolidts #3)

- Docs
  – Added guides for availability warnings, assembly.part and explicit adapter cables (#929, #935, #936)
