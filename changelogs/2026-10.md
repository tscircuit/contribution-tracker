# Changelog 2026-10

- Cross-view navigation
  – Schematic viewer “Show on PCB” action (#283) + runframe support (#5568)
  – PCB viewer focus controller to jump to parts from other views (#1068)

- Part pricing & availability
  – Show JLC price/stock inside schematic part details (#282)
  – New JLC parts-engine backend (#61) and CLI enables availability checks by default (#5180)
  – Core issues warnings only for user-specified suppliers (#4424, #4429)

- Generic assembly parts & mechanical models
  – Core + props add generic assembly.part records (#4444, #919)
  – Modelprinter 0.0.18 and jscad-electronics add >15 new mechanical model contracts/renderers (shaft collars, T-slot, springs, etc.) (#4452, #428-#433)

- Fabrication & rendering improvements
  – Filled fabrication note paths now render everywhere (circuit-to-svg #812, canvas #300, pcb-viewer #1074)
  – Dark centers on tented vias in SVG/Canvas/GLTF (#814, #304, #242)
  – Solder-paste for pill pads generated (#4434)
  – Custom pin-row courtyards supported in Footprinter (#908)

- Return-current simulation visuals
  – Circuit-json schema for PCB return-current data (#887) + SVG viewer overlay (#818)

- Schematic quality tools
  – Placement analysis detects resistors across pins, backward LED chains, mis-aligned RC branches (#211, #215, #218)

- Miscellaneous UX
  – PCB viewer remembers rendering engine choice (#1072)
  – CLI removes obsolete svg-xray alias (#5201)
  – Docs cover availability warnings, adapter cables, assembly.part examples (#929, #936, #935)
