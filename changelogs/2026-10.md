# Changelog 2026-10

- Cross-view navigation: right-click “Show on PCB” in the schematic now zooms the PCB and 3D viewers to the selected part ([schematic-viewer #283](https://github.com/tscircuit/schematic-viewer/pull/283), [pcb-viewer #1068](https://github.com/tscircuit/pcb-viewer/pull/1068), [runframe #5568](https://github.com/tscircuit/runframe/pull/5568)).
- Live part pricing: schematic part details display JLC price & stock in real time ([schematic-viewer #282](https://github.com/tscircuit/schematic-viewer/pull/282)) powered by the new JLC parts-engine backend ([parts-engine #61](https://github.com/tscircuit/parts-engine/pull/61)).
- Availability warnings: CLI and Core can now warn when a chosen supplier is out of stock—enabled by default in the CLI ([core #4424](https://github.com/tscircuit/core/pull/4424), [cli #5180](https://github.com/tscircuit/cli/pull/5180)).
- Tented-via shading: dark centers are rendered across SVG, Canvas and PCB viewers for clearer inspection ([core #4432](https://github.com/tscircuit/core/pull/4432), [circuit-to-svg #814](https://github.com/tscircuit/circuit-to-svg/pull/814), [circuit-to-canvas #304](https://github.com/tscircuit/circuit-to-canvas/pull/304), [runframe #5610](https://github.com/tscircuit/runframe/pull/5610)).
- Filled fabrication notes: filled paths from EasyEDA and Circuit JSON now survive every converter and viewer ([easyeda-converter #595](https://github.com/tscircuit/easyeda-converter/pull/595), [circuit-to-svg #812](https://github.com/tscircuit/circuit-to-svg/pull/812), [circuit-to-canvas #300](https://github.com/tscircuit/circuit-to-canvas/pull/300)).
- Return-current simulation workflow: new schemas, props and SVG overlay let you visualise simulated PCB return-current results ([circuit-json #887](https://github.com/tscircuit/circuit-json/pull/887), [props #926](https://github.com/tscircuit/props/pull/926), [circuit-to-svg #818](https://github.com/tscircuit/circuit-to-svg/pull/818), [simulate-return-current #15](https://github.com/tscircuit/simulate-return-current/pull/15)).
- Schematic placement analyser catches more mistakes: now flags crossed chip resistors, backwards LED chains, misaligned parallel RCs, stray diode branches, off-pin inductors and sideways transistor stages ([schematic-placement-analysis #211](https://github.com/tscircuit/circuit-json-schematic-placement-analysis/pull/211), [#215](https://github.com/tscircuit/circuit-json-schematic-placement-analysis/pull/215), [#218](https://github.com/tscircuit/circuit-json-schematic-placement-analysis/pull/218), [#221](https://github.com/tscircuit/circuit-json-schematic-placement-analysis/pull/221), [#230](https://github.com/tscircuit/circuit-json-schematic-placement-analysis/pull/230), [#236](https://github.com/tscircuit/circuit-json-schematic-placement-analysis/pull/236)).
- Generic assembly parts: JSON & Core now support arbitrary non-electronic parts placed on the assembly drawing ([props #919](https://github.com/tscircuit/props/pull/919), [core #4444](https://github.com/tscircuit/core/pull/4444)).
- Reference surfaces & colour overrides: specify mounting reference planes and printed-part colours; respected in renders and exports ([circuit-json #889](https://github.com/tscircuit/circuit-json/pull/889), [props #923](https://github.com/tscircuit/props/pull/923), [core #4448](https://github.com/tscircuit/core/pull/4448)).
- Mechanical library expansion: added T-slot extrusion system, shaft collars & couplers, threaded rods, ISO fasteners, compression/torsion springs, cable grommets and more (model contracts & renderers in [modelprinter #20–65](https://github.com/tscircuit/modelprinter/pulls?q=is%3Apr+is%3Aclosed+20..65) and [jscad-electronics #409–449](https://github.com/tscircuit/jscad-electronics/pulls?q=is%3Apr+is%3Aclosed+409..449)).
- 3D viewer fixes: interactive viewer now shows cad_cable meshes and offers reordered context menu items ([3d-viewer #1017](https://github.com/tscircuit/3d-viewer/pull/1017), [#1015](https://github.com/tscircuit/3d-viewer/pull/1015)).
- PCB style analysis CLI: new pipeline detects problematic staircase routing and other trace-style issues ([pcb-style-analysis #1](https://github.com/tscircuit/circuit-json-pcb-style-analysis/pull/1)).
