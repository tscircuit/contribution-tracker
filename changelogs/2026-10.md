# Changelog 2026-10

Highlights for 2026-10

- Cross-view navigation
  – Schematic “Show on PCB” action (schematic-viewer #283) with PCB focus controller (pcb-viewer #1068) and Runframe support (#5568).

- Part sourcing & availability
  – JLC price/stock shown in schematic part details (#282).
  – New JLC parts-engine backend (#61) and CLI enables availability checks by default (cli #5180).

- Schematic quality tooling
  – Schematic-placement-analysis 0.0.46+ with new misplacement detectors (analysis #211, #215, #218).
  – CLI & schematic-viewer aligned to latest analysis engine (viewer #284, cli #5188).

- Fabrication note & via rendering polish
  – Filled fabrication note paths now preserved across EasyEDA converter (#595), canvas (#300), svg (#812) and WebGPU (#20).
  – Dark centers on tented vias in SVG/canvas/PCB-viewer (core #4432, svg #814, canvas #304, pcb-viewer #1074).

- Mechanical & assembly extensions
  – Generic assembly.part props + core support (props #923, core #4444).
  – Dozens of new modelprinter contracts & JSCAD renderers (T-slot, bearings, springs, shaft hardware, hollow arm tube, etc.).
  – Cableprinter generic adapter cables & bullet connectors (#10, #8) with 3D viewer rendering fix (#1017).

- Simulation & analysis
  – Return-current simulation schemas added (circuit-json #887) and SVG viewer renders results (#818).
  – Checks library fixes false copper-pour shorts (#396).

- Viewer UX tweaks
  – PCB viewer remembers rendering engine (pcb-viewer #1072).
  – 3D viewer gains camera presets & GLB export (svg.tscircuit.com #2476) and reordered context menu (#1015).

- Footprinting
  – Custom pin-row courtyard sizing supported (footprinter #908) and solder-paste generation for pill pads (core #4434).

- Misc.
  – Docs updated for availability warnings, adapter cables, assembly.part (docs #929, #936, #935).
  – Numerous version bumps & internal package syncs omitted for brevity.
