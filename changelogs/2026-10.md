# Changelog 2026-10

- Cross-view navigation: “Show on PCB” now appears in the schematic context menu and smoothly centers the same part in the PCB & 3D viewers ([schematic-viewer #283](https://github.com/tscircuit/schematic-viewer/pull/283) · [pcb-viewer #1068](https://github.com/tscircuit/pcb-viewer/pull/1068) · [runframe #5568](https://github.com/tscircuit/runframe/pull/5568) · [3d-viewer #1015](https://github.com/tscircuit/3d-viewer/pull/1015))
- Real-time sourcing: JLCPCB price & stock are shown in schematic part details and the parts-engine can now query JLC availability; CLI enables availability checks by default ([schematic-viewer #282](https://github.com/tscircuit/schematic-viewer/pull/282) · [parts-engine #61](https://github.com/tscircuit/parts-engine/pull/61) · [cli #5180](https://github.com/tscircuit/cli/pull/5180))
- PCB viewer remembers your preferred rendering engine between sessions ([pcb-viewer #1072](https://github.com/tscircuit/pcb-viewer/pull/1072))
- Cables now render correctly in the interactive 3D viewer ([3d-viewer #1017](https://github.com/tscircuit/3d-viewer/pull/1017))
- Dark centers on tented vias are rendered across SVG, canvas and GLB outputs ([core #4432](https://github.com/tscircuit/core/pull/4432) · [circuit-to-svg #814](https://github.com/tscircuit/circuit-to-svg/pull/814) · [circuit-to-canvas #304](https://github.com/tscircuit/circuit-to-canvas/pull/304) · [circuit-json-to-gltf #242](https://github.com/tscircuit/circuit-json-to-gltf/pull/242))
- Filled fabrication-note paths now appear in SVG, canvas, WebGPU and EasyEDA conversions ([circuit-to-svg #812](https://github.com/tscircuit/circuit-to-svg/pull/812) · [circuit-to-canvas #300](https://github.com/tscircuit/circuit-to-canvas/pull/300) · [circuit-json-webgpu #20](https://github.com/tscircuit/circuit-json-webgpu/pull/20) · [easyeda-converter #595](https://github.com/tscircuit/easyeda-converter/pull/595))
- Return-current simulation results can be overlaid on PCB SVG exports ([circuit-to-svg #818](https://github.com/tscircuit/circuit-to-svg/pull/818))
- Generic mechanical parts can now be embedded with the new `assembly.part` support ([props #919](https://github.com/tscircuit/props/pull/919) · [core #4444](https://github.com/tscircuit/core/pull/4444))
- Schematic placement analysis detects several new anti-pattern cases (e.g., resistors across IC pins, mis-aligned RC branches, backward LED chains) ([schematic-placement-analysis #211](https://github.com/tscircuit/circuit-json-schematic-placement-analysis/pull/211) · [#215](https://github.com/tscircuit/circuit-json-schematic-placement-analysis/pull/215) · [#218](https://github.com/tscircuit/circuit-json-schematic-placement-analysis/pull/218) · [#221](https://github.com/tscircuit/circuit-json-schematic-placement-analysis/pull/221))
- First release of PCB trace-style analysis CLI with visual issue artifacts ([pcb-style-analysis #2](https://github.com/tscircuit/circuit-json-pcb-style-analysis/pull/2))
