# Changelog 2026-10

- Added "Show on PCB" cross-view navigation: schematic context menu triggers component focus in PCB viewer ([schematic-viewer #283](https://github.com/tscircuit/schematic-viewer/pull/283), [runframe #5568](https://github.com/tscircuit/runframe/pull/5568), [pcb-viewer #1068](https://github.com/tscircuit/pcb-viewer/pull/1068))

- CLI enables part-availability checks by default and supports supplier-specific warnings ([cli #5180](https://github.com/tscircuit/cli/pull/5180), [core #4424](https://github.com/tscircuit/core/pull/4424), [core #4429](https://github.com/tscircuit/core/pull/4429))
- Automatic cable alignment: connector pin-1 positions computed and consumed by renderers for correctly oriented plugs ([core #4420](https://github.com/tscircuit/core/pull/4420), [circuit-json #878](https://github.com/tscircuit/circuit-json/pull/878), [circuit-json-to-gltf #240](https://github.com/tscircuit/circuit-json-to-gltf/pull/240))
- Assembly generator now infers JST PH/SH motor cables and respects explicitly selected cable models ([core #4417](https://github.com/tscircuit/core/pull/4417), [core #4416](https://github.com/tscircuit/core/pull/4416))
- Enhanced rendering: filled fabrication note paths, consistent opacity, and dark centers on tented vias across SVG/Canvas outputs ([circuit-to-svg #812](https://github.com/tscircuit/circuit-to-svg/pull/812), [circuit-to-canvas #300](https://github.com/tscircuit/circuit-to-canvas/pull/300), [circuit-to-svg #814](https://github.com/tscircuit/circuit-to-svg/pull/814), [circuit-to-canvas #302](https://github.com/tscircuit/circuit-to-canvas/pull/302))
- Massive 3D library expansion: new renderers & model contracts for T-slot extrusions, bearings, shaft collars/couplers, springs, screws, nuts, bushings, cable grommets, threaded rods, gussets, and more ([jscad-electronics #417](https://github.com/tscircuit/jscad-electronics/pull/417), [jscad-electronics #439](https://github.com/tscircuit/jscad-electronics/pull/439), [modelprinter #33](https://github.com/tscircuit/modelprinter/pull/33), etc.)
- New warning schema flags improper schematic sheet styling ([circuit-json #881](https://github.com/tscircuit/circuit-json/pull/881))
