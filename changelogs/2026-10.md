# Changelog 2026-10

- Cross-view navigation
  – Schematic → PCB: “Show on PCB” added to schematic context menu (schematic-viewer #283, runframe #5568)
  – PCB → Schematic: new focus controller lets PCB viewer jump back to schematic parts (pcb-viewer #1068)

- Part availability & pricing
  – JLC price/stock shown in schematic part details (schematic-viewer #282)
  – Parts-engine JLC lookup service introduced (parts-engine #61) and enabled by default in CLI (cli #5180)
  – Core warns about supplier availability only for selected suppliers and can be toggled (core #4424, #4429)
  – Docs explain availability warnings & opt-out (docs #929)

- Mechanical & 3D modeling
  – 20+ new mechanical model contracts/renderers (modelprinter & jscad-electronics: shaft collars, T-slot extrusions, springs, bearings, screws, gussets, etc.)
  – Model flags propagated through core and 3D viewers (core #4452, jscad-electronics #445)
  – SVG/GLB viewers gain camera presets and downloadable GLB files (svg.tscircuit.com #2476, #2484)

- PCB / schematic visualization improvements
  – Dark centers rendered on tented vias across SVG, Canvas, GLB (core #4432, circuit-to-svg #814, circuit-to-canvas #304, circuit-json-to-gltf #242)
  – Filled fabrication note paths now render consistently in SVG, Canvas, EasyEDA import (circuit-to-svg #812, circuit-to-canvas #300-302, easyeda-converter #595)
  – Schematic sheet styling & size warnings rendered (circuit-to-svg #815, core #4440)

- Assembly enhancements
  – Generic assembly.part + reference-surface props and schema (props #919, core #4444, circuit-json #891)
  – Automatic cable plug alignment using computed pin-1 positions (core #4420)

- Schematic placement analysis
  – New detectors: resistors over chip pins, backward LED chains, mis-aligned grounded RC branches (schematic-placement-analysis #211, #215, #218)
  – CLI & schematic-viewer updated to analysis v0.0.46 (cli #5188, schematic-viewer #284)

- Manufacturing outputs
  – Solder-paste generation for pill pads (core #4434)
  – Copper-pour false-positive fix in checks (checks #396)

- Miscellaneous fixes & UX
  – PCB viewer remembers rendering engine preference (pcb-viewer #1072)
  – 3D viewer now shows cad_cable elements and reorganized context menu (3d-viewer #1015-1017)
  – Circuit-json sheet origin preservation (core #4456, circuit-json-to-tscircuit #186)

(Version bumps & routine package updates omitted for brevity.)
