# Changelog 2026-10

- Cross-view navigation: "Show on PCB" added to schematic viewer & supported by runframe; PCB viewer gains component focus controller.
- Supply chain insights: JLC price/stock now shown in schematic part details; CLI & core default to parts-engine availability checks.
- Placement quality: Schematic-placement-analysis detects backwards LED chains, mis-aligned RC branches & resistor-over-pin errors (v0.0.50).
- Fabrication visuals: Filled fabrication note paths, dark tented-via centers & uniform opacity rendered across SVG, Canvas, EasyEDA & GLTF pipelines.
- Assembly modeling: New generic assembly.part prop & reference-surface schemas; core supports it and 3D viewer correctly renders cad_cable.
- Mechanical library expansion: 20+ JSCAD/modelprinter contracts for fasteners, shaft hardware, T-slot extrusions, springs, grommets & positioning arms.
- Cable workflow: Generic adapter cables & bullet connector sizes in cableprinter; core computes connector pin-1 alignment.
- PCB accuracy: Core generates solder paste for pill pads, preserves bus target lengths, warns on non-standard sheet sizes, keeps fixed-size sheets at origin.
- Parts-engine: JLC availability/price lookup service shipped.
- CLI quality-of-life: Part availability checks default on; redundant svg-xray alias removed; schematic-placement-analysis 0.0.46 bundled.
- Checks & DRC: Copper-pour false-short fix (checks 0.0.242); footprinter allows custom courtyard rows.
- Documentation: Guides for availability warnings, assembly.part, flex bends & adapter cables published.
- Misc: PCB viewer remembers rendering engine; jscad-to-step/parasolids merge coplanar faces; bus-lanes-solver routes full AM3352 SBC sample.
