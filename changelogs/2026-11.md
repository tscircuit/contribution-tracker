# Changelog 2026-11

- Schematic Viewer: Internal component IDs no longer shown in the details pane (schematic-viewer #304)
- PCB Viewer: Fixed duplicate “mm” in anchor labels (pcb-viewer #1191); sped up WebGPU copper-pour tesselation (pcb-viewer #1163); upgraded WebGPU renderer to 0.0.16 (pcb-viewer #1185); hover overlays stay inside the viewport when zoomed (pcb-viewer #1153); component-search button now matches host CSS (pcb-viewer #1181)
- 3D Viewer: Keeps camera position when switching scenes (3d-viewer #1121); right-click isolate / single-model GLTF download and optional PCB hide (3d-viewer #1091, #1092)
- Core Engine: Preserves BGA dog-bone fan-outs through ground pours (core #5223) and allows ground-plane routing past length checks (core #5182); sets default board thickness to 1.6 mm (core #5121); emits cad_assembly_bom_item records and Dagre/SVG System blocks (core #5113, #5112); eliminates panel mouse-bite/sliver slot artifacts (core #5076, #5071)
- System Block Diagrams: Added JSON schemas, props and resolved geometry records (circuit-json #959, props #972); SVG rendering & curved-route arrows (circuit-to-svg #895, #900); CLI builds & SVG snapshots (cli #5698, #5701); viewer integration in Runframe & svg.tscircuit.com (runframe #6085, svg.tscircuit.com #2800)
- Metadata Preservation: Custom KiCad symbol/footprint properties now round-trip through Circuit JSON and KiCad exports (circuit-json #979, #975; circuit-json-to-kicad #873)
- Autorouter: DDR-mesh performance boosts, copper-pour/clearance fixes, and version bumped to 0.0.1051 (autorouter #3547, #3529, #3496, #3477)
- CLI / Converters: Adopted shared footprinter glTF exporter (tscircuit #6223); STEP export handles pill drills (circuit-json-to-step #177); optional Bun-compatible runtime (cli #5671)
- Circuit-JSON-Util: Via matching tolerates small offsets; copper pours move with PCB transforms (circuit-json-util #283, #290)
- JLCSearch: Displays verified SRAM/DRAM and processor clock & core counts; fixes RK3576 coverage (jlcsearch #630, #629, #628)
- Documentation: Added system-diagram guide, simulation elements docs, and purchasing-props listings (docs #980, #996, #1000)
