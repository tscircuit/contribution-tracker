# Changelog 2026-11

- Schematic Viewer (#304)
  – Internal component IDs are no longer exposed in the details pane.

- PCB Viewer
  – Fixed duplicate “mm” in anchor-offset labels (#1191).
  – Matched component-search button height to host CSS (#1181).
  – Eliminated hover-overlay clipping when zoomed (#1153 → surfaced in tscircuit.com #5689).
  – WebGPU renderer upgrades to 0.0.16 (#1185) with faster copper-pour triangulation via Earcut update (#1163).

- Core Engine
  – Maintains BGA dog-bone fan-outs when adding ground pours (#5223).
  – Allows ground-plane routing past trace-length checks (#5182) and skips redundant autoroutes (#5143).
  – Default board thickness set to 1.6 mm with missing-stack-up warning (#5121, #5109).
  – Adds Dagre-layout System-block TSX support and SVG snapshots (#5112).
  – Numerous autorouter/bus-lane solver bumps improving DDR and power-plane performance (#5243, #5235, #5168, #5153, #5146, #5129–5122).

- Circuit-JSON & Props
  – Preserves custom KiCad symbol/footprint metadata (#979, #975, core-side #5241).
  – Adds resolved-geometry System Block records and curved Bézier routing schema (#959, #962).
  – New purchasing & system-block diagram props plus stricter courtyard validation (#973, #972, #974; kicad-mod-cache #31).

- CLI
  – Supports System-diagram exports & SVG builds (#5698–5701) and isolates compiler from TypeScript 7 projects (#5696).
  – Fixes STEP/panel export regressions (#5663, #5692).

- 3D Viewer
  – Keeps camera position when swapping GLB scenes (#1121) and releases WebGL context on teardown (#1095).
  – Adds right-click Isolate & hide-board features; single-model GLTF export (#1091–1092).

- circuit-json-util
  – Via-matching now tolerates small position error (#283) and moves copper pours with PCB transforms (#290).

- circuit-to-svg
  – Renders System Block diagrams and curved routes with arrowheads (#895, #900).

- Autorouter (tscircuit-autorouter)
  – Major DDR robustness/perf fixes: respect board clearance (#3529), release temp memory (#3548), preserve fixed traces & via contacts (#3520, #3504), repair split pads/drills (#3493, #3471).

- Documentation & Site
  – Added System Diagram guide, simulation docs, purchasing-prop references (#980, #996, docs #1000).
  – Package pages now show interactive System diagrams and refined UI/UX (#5699–5708).

- Miscellaneous Fixes
  – Copper-pour/BGA dog-bone, panel slot rounding, mouse-bite web width, split ground ports, shared-rail schematic trace solver, EasyEDA import resistance, etc.

Overall, November 2026 focused on reliability (ground-plane, DDR, copper pours), richer System-diagram support across viewers, and enhanced metadata preservation for KiCad workflows.
