# Changelog 2026-07

2026-07 Highlights
- Schematic viewer: hover a net to auto-fade all unrelated nets & chips (#237)
- Core/solver stack
  – Port facing directions now respected end-to-end (core #2614, sts #645)
  – Custom schematic symbols & custom footprint port hints supported (core #2629, #2617)
  – New “pipeline 7” set as default autorouter with option to ignore existing PCB routes (core #2618, #2632)
- Autorouter engine
  – BGA grid, same-net via merging & endpoint snapping fixes + global/comp topology merge, via-count stats, differential-pair support (AR #1545, #1537, #1536, #1592, #1556, #1583)
  – New decoupling-cap row solver & collision fix (matchpack #155, #153)
- Schematic trace routing
  – Short-trace, overlap & ratsnest-free visual fixes; dedicated corridors when escaping net-label blocks (#638, #648, #649, #646)
- CLI / tooling
  – “tsci check-shorts” command with bitmap PCB short detection & debug artifacts (cli #3587, check-shorts #7-11)
  – Autorouter debug image & message output (cli #3610-3612)
- File converters
  – Gerber: preserve silkscreen text case & filled silkscreen graphics, subtract overlapping cutouts (#120, #122, #123)
  – KiCad: proper board-outline minus cutouts, mirror bottom silkscreen text, legacy footprint & connectivity support (#365, #373, k2cj #160, #163)
- SVG / viewer
  – Tag net-label elements for tooling & remove hover CSS from base SVG (c-to-svg #602)
  – Comprehensive PCB bounds now counts all element types (#605, #607)
- Symbol & props library
  – Fixed switch/MOSFET terminal alignment (schematic-symbols #436)
  – SymbolProp now accepts element arrays; MOSFET connection metadata added (props #718, #720)
- Simulation & NGSpice
  – Prevent runSim rejection on ngspice errors; engine bumped to 1.7.6 (EEcircuit-engine #7, ngspice-spice-engine #24)
- Website / editor
  – 3D package preview fix with native PNG rendering (tscircuit.com #3882)
  – Monaco editor: file-type icons, path normalization, hover/selection visibility (monaco-code-editor #17-24, #28)
- Documentation: new QR-Code silkscreen & custom autorouter hint guides (docs #773, #790)
