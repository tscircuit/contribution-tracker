# Changelog 2026-07

Key changes delivered in July 2026

- Interactive schematic viewing – nets now highlight on hover (schematic-viewer #237).
- Smarter schematic routing – core passes pin-facing data to the trace solver and fixes out-of-order pin labels (core #2614, #2615).
- Customisation boost – custom footprint port hints can override LED aliases (core #2617) and SymbolProp now accepts element arrays/MOSFET connections (props #718, #720).
- Autorouter v7 upgrades – grid-aligned BGA routing, same-net-via fixes, differential-pair support, global/-component topology merge & richer debug output (autorouter #1545 #1552 #1583 #1592 plus version bumps; core #2618, #2635).
- Decoupling capacitor placement solver reduces collisions and lays out rail rows (matchpack #153, #155; core #2633).
- Trace-solver stability – respects provided pin facing, eliminates shorts, cleaner snapshots & label-snapping improvements (schematic-trace-solver #645, #648, #646, #654, #649).
- PCB export accuracy – preserves silkscreen text case, renders silkscreen graphics, subtracts overlapping cut-outs (c-json→Gerber #120, #122, #123).
- KiCad round-trip reliability – fixes edge-cut subtraction, text mirroring, footprint & connectivity handling (c-json→KiCad #365, #373, #375; kicad→c-json #160, #162, #163).
- SVG/3-D rendering – comprehensive bounds counting, hover styling removed, standalone simulation-graph SVGs & native PNG previews (c-to-svg #605 #607 #602; svg.tscircuit.com #1763; tscircuit.com #3882).
- New “check-shorts” package with bitmap-based PCB short detection and CLI integration (`tsci check-shorts`) (check-shorts #7-14; cli #3587).
- EE simulation robustness – runSim now handles ngspice failures cleanly (EEcircuit-engine #7).
- System-block-designer gains AI assistant & UI tweaks (system-block-designer #55-57).
- Monaco code editor enhancements – file-type icons, better path handling, visible tree-view states & fixed Git installs (monaco-code-editor #17, #21, #24, #28).
- Docs – new QR-code silkscreen guide and custom autorouter hint documentation (docs #773, #790).
- Infrastructure – Vercel build regression fixed by aligning package versions (tscircuit.com #3850).
